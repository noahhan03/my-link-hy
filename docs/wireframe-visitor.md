## 🗒️ 참고

- **빈 상태 (링크 0개):** 링크 영역에 `"아직 등록된 링크가 없습니다"` 안내 표시
- **SNS 0개:** SNS 아이콘 영역 자체를 숨김
- **소개글 미입력:** bio 영역 숨김, 이름 바로 아래에 SNS 아이콘 표시
- **프로필 사진 없음:** 이니셜 또는 기본 아바타 아이콘으로 대체
- **테마 적용:** 배경색, 텍스트색, 링크 버튼 스타일이 선택된 테마에 따라 변경
